Hi, I'm an infrastructure / cloud engineer with a strong cybersecurity focus (ESIEE Paris, 3 years at CNP Assurances Group), working toward senior cloud, infrastructure & security roles.
This repo is where continuous, hands-on learning lives in the open. I use Hack The Box to go deep on how systems and networks actually work — and how they break. Infra/cloud is my foundation, but security runs through everything I do. Alongside the labs, it is my living knowledge base (cheatsheets, notes) and the tracker for my certification path, with two focus tracks: Cloud and AI.

Continuum map
Where I started: infrastructure and support. Keeping systems running, learning Linux and Windows environments, networks, and virtualization in a large insurance group (CNP Assurances).
Where I am: moving from operations toward cloud & infrastructure engineering: Azure first, then AWS, with containers, orchestration and Infrastructure as Code as the daily toolkit. HTB labs sharpen my understanding of how services, trust and networks behave when they are misconfigured, which makes me better at building them properly.
Where I'm heading: senior cloud, infrastructure & security roles, with two focus areas:
Cloud: Azure & AWS, Kubernetes, Terraform, CI/CD
AI: building and operating AI infrastructure (GPUs, clusters, pipelines), and securing it
